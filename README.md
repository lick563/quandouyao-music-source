quandouyao‑music‑source
 
多源音乐扩展插件，轻量化，为客户端拓展更多音乐音源能力。
 
📖 项目介绍
 
quandouyao‑music‑source 是一款第三方音乐音源插件。
致力于给支持插件协议的音乐客户端扩充曲库资源，整体架构轻量化，低内存占用，模块式设计，便于后续新增、维护音源。
 
⚠️ 版权免责声明
本项目仅作技术学习、程序研究交流使用。
项目本身不缓存、不存储、不分发任何受版权保护的音频文件。
全部音乐内容均调用互联网公开第三方接口获取。
禁止任何商业使用行为。使用本项目产生的一切责任，由使用者自行承担。

✨ 项目特性
 
- 🚀 轻量高效：精简逻辑，低资源消耗，手机端也可流畅运行
​
- 🔗 多音源聚合：对接多方公开接口，扩充检索与播放资源
​
- 🧩 模块化架构：音源独立模块，新增、移除音源简单方便
​
- 📱 多客户端适配：兼容遵循标准插件协议的各类音乐客户端
 
📦 安装
 
1. 在 Releases 下载最新发行版插件文件
​
2. 打开音乐客户端 → 插件管理
​
3. 导入下载好的插件包，确认启用
 
不同客户端导入操作存在区别，请参考对应客户端文档。
 
📝 使用指南
 
1. 成功导入插件后，进入插件配置页
​
2. 根据自身需求开关各个音源源
​
3. 返回主界面，即可搜索、播放扩展源内的音乐资源
